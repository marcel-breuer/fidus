# Fidus shared agent skills

Always read the root [AGENTS.md](../../AGENTS.md) first. Then load only the skill(s) applicable to the task. Skills supplement the rules and never override them.

| Task | Skill |
| --- | --- |
| Any SvelteKit UI change | [Frontend components and i18n](frontend-components-i18n/SKILL.md) |
| New module (chat, files, tasks, later calendar) | [Implement module](implement-module/SKILL.md) |
| Schema, models, migrations, pgvector | [Database change](database-change/SKILL.md) |
| Dockerfiles, Compose, start script, runtime | [Docker change](docker-change/SKILL.md) |
| Adding tests or fixing regressions | [Write tests](write-tests/SKILL.md) |
| Releases, tags, dependency updates | [Release change](release-change/SKILL.md) |
